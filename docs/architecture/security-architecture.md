# Security Architecture

- **Zero-Trust Multi-Tenancy**: Agencies can only view cases assigned to them or shared via cross-agency delegation.
- **Anonymous Whistleblower Protection**: Zero IP logging or submitter tracking on anonymous reports.
- **Digital Chain of Custody**: Cryptographic integrity (SHA-256) of every uploaded file.
- **Append-Only Auditing**: Logs cannot be modified or deleted.
- **MFA Architecture**: Multi-factor authentication support for agency personnel.
