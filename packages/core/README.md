# @catcham/core

Core domain and infrastructure library providing shared abstractions across CATCHAM:
- **Workflow Engine**: State machine and execution management for multi-stage processes.
- **Rules Engine**: Configurable, decoupled policy and validation evaluator.
- **Upload Management**: S3/MinIO chunked, secure upload handlers and security filters.
- **Shared Domain Primitives**: Base entities, Domain Events, value objects, cryptographic helpers, and pagination.
