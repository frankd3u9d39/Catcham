# CATCHAM Multi-Agency Web Application

Role-aware Web Portal engineered with Next.js 14, Tailwind CSS, shadcn/ui patterns, and TanStack React Query.

## Key Perspectives Supported
1. **Public & Whistleblowers**: Secure anonymous submission, tracker lookup.
2. **Investigators**: Case workbench, task checklist, digital evidence inspector.
3. **Supervisors & Agency Heads**: Assignment, escalation control, SLA reports.
4. **Platform Administrators**: Multi-agency onboarding, jurisdiction geofencing, workflow & rule configuration.
