# CATCHAM Mobile Application

React Native (Expo) whistleblower, citizen reporting, and tracking client.

## Core Capabilities
- **Incident & Whistleblower Submission**: Fast offline-capable submission.
- **GPS Jurisdiction Pinning**: Captures precise coordinates for PostGIS routing.
- **Direct Camera Intake**: Media captured and hashed immediately for chain-of-custody.
- **Anonymous Tracking**: Citizens can track report progress using their private reference secret.
